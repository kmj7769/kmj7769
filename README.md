## Introduction

서비스 요구사항과 운영 제약을 기준으로 클라우드 인프라와 모니터링·관측가능성을 구성하고, 운영 문제를 분석·개선해 온 엔지니어 김민준입니다. </br>

문제를 **스스로 정의**하고 해결에 뛰어들어, **경험**과 **실패**를 통해 **배우려는 자세**를 **지향**합니다. </br>

협업에서는 각 역할의 요구를 이해하고, 서로 다른 의견을 수용하고 조율합니다. </br>
